# Agent instructions

## Documentation

When you change the ShellScript class library or public language surface, follow the skill:

**`.agents/skills/update-api-documentation/`**

At minimum, run `python3 scripts/generate-api-docs.py` and commit the updated files under `docs/api/`.

Human-readable docs site: `docs/` (Jekyll + Just the Docs). See `docs/README-docs.md`.
