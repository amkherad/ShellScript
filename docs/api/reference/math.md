# `Math`

Static class library API. Platform backends (Unix-Bash, Windows-PowerShell, Windows-Batch) implement subsets of these members.

## Methods

### `number Math.Abs()`

Returns the absolute value of the number.

### `number Math.Ceiling()`

Returns the smallest integral value greater than or equal to the number.

### `number Math.Floor()`

Returns the largest integral value less than or equal to the number.

### `number Math.Max(number Second)`

Returns the larger of two numbers.

| Parameter | Type |
|-----------|------|
| `Second` | `number` |

### `number Math.Min(number Second)`

Returns the smaller of two numbers.

| Parameter | Type |
|-----------|------|
| `Second` | `number` |

### `number Math.Pow(number Exponent)`

Returns a number raised to the specified power.

| Parameter | Type |
|-----------|------|
| `Exponent` | `number` |

### `number Math.Round()`

Rounds a number to the nearest integral value.

### `int Math.Sign()`

Returns -1, 0, or 1 depending on the sign of the number.

### `number Math.Sqrt()`

Returns the square root of a number.

### `number Math.Truncate()`

Returns the integral part of a number.
